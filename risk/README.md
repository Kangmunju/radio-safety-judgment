# ⑤ 위험성 평가 (`risk/`)

**팀 DB에 저장된 무전 중 정비요청마다, 작업 후 위험성평가 엑셀을 한 장씩 만듭니다.**

## 실행 (저장소 맨 위 폴더에서)

```bash
pip install scikit-learn joblib openpyxl
python db/build_db.py --with-stt --classify --with-risk-data   # 1) 팀 DB 만들기 (무전 + 분류 + 위험성평가 표)
python risk/run.py                                              # 2) 정비요청 전부 → 엑셀
python risk/run.py S01                                          #    시연 장면(S01)만
```

- 결과 엑셀: `risk/output/` — 파일 이름 = 그 무전의 녹음 파일 이름
  예: `S01_01_A_위험성평가.xlsx` = 장면 S01의 1번째 무전(A가 말함) "3번 컨베이어 롤러 점검하고 낙광 청소해 줘"
- 초안 기록: 팀 DB의 `risk_draft` 표 (무전 1건에 작업이 2개면 2줄). 다시 실행해도 겹치지 않습니다.

## 안에서 하는 일 (5단계)

1. 팀 DB(`db/hackathon.db`)의 무전(`radio_message`)을 순서대로 읽습니다. 분류(cls)가 비어 있으면 CLS로 채웁니다.
2. **정비요청만** 고릅니다. 설비는 DB의 설비 연결 → 없으면 문장 속 설비 이름으로 찾습니다(`db_api.find_equipment`).
3. 문장에서 **무슨 부품을 뭘 하는지** 찾습니다. 예: "롤러 점검하고 낙광 청소해 줘" → 롤러 점검, 낙광 청소
4. 팀 DB의 **작업별 위험요인·감소대책 표**(`risk_template`, `risk_step`)에서 그 작업의 줄을 꺼내고, 초안을 `risk_draft`에 저장합니다.
5. KRAS 양식 엑셀에 채웁니다. 같은 설비의 "LOTO 걸었습니다", "정비 완료" 무전은 위쪽 **작업 기록** 줄에 적습니다.

## 엑셀 보는 법

| 위치 | 내용 |
|---|---|
| 공정명 | 3번 컨베이어(CV-03) 정비 — 롤러 점검, 낙광 청소 |
| 작업 기록 (2행) | 작업 요청 → LOTO 적용 → 정비 완료·LOTO 해제 무전 |
| 본문 | 작업 준비 → 작업별 위험요인·감소대책 → 작업 마무리 |
| 가능성·중대성·위험성 | **빈칸 — 담당자가 입력** (`요인 및 등급` 탭의 등급표를 보고) |
| 맨 아래 ※ | 담당자가 확인할 것 (설비 확인 필요, 작업 미확인 등) |

## 자주 받을 질문

- **위험요인·대책 내용은 어디서 왔나요?**
  사용자가 입력했다고 가정한 예시입니다. 한국가스공사 위험성평가 표준모델 문장의 말투를 그대로 쓰고, 설비·부품·작업 단어만 바꿨습니다.
  (`data/source_rows.csv` = 바탕이 된 원문 15줄)
- **"설비 확인 필요"는 언제 붙나요?**
  정비요청 무전에서 설비 번호가 안 들렸을 때입니다. 바로 뒤 복창("3번 컨베이어 … 알겠습니다")의 설비로 채우고 확인 필요로 표시합니다.
- **"작업 미확인"은 언제 붙나요?**
  부품 이름이 잘못 들려(예: "테일 풀리" → "테일 플릿") 작업을 못 찾았을 때입니다. 설비 공통 항목(작업 준비·마무리)만 채웁니다. NER 사전에 그 오인식 단어를 추가하면 해결됩니다.
- **새 작업을 추가하려면?**
  `src/build_templates.py`의 `WORKS`에 한 줄 추가 → `python risk/src/build_templates.py` → `python risk/src/db.py`(팀 `db/risk_data.sql` 갱신) → 1)부터 다시 실행

## 폴더

```
risk/
├─ run.py                  실행 파일 (이것만 실행하면 됨)
├─ src/
│  ├─ make_draft.py        본체 (팀 DB 읽기 → 초안 저장 → 엑셀)
│  ├─ build_templates.py   작업별 위험요인·감소대책 표 만들기 (작업을 추가할 때만)
│  └─ db.py                그 표를 팀 db/risk_data.sql 로 내보내기
├─ data/
│  ├─ risk_template.csv    작업 9개 (팀 DB risk_template 과 같은 칸)
│  ├─ risk_step.csv        작업별 위험요인·감소대책 57줄 (팀 DB risk_step 과 같은 칸)
│  ├─ source_rows.csv      바탕이 된 가스공사 원문 15줄
│  └─ kras_template.xlsx   KRAS 양식 원본
└─ output/                 결과 엑셀
```
